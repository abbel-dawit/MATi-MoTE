# App logos (optional)

Drop official logo files here to show them on the App cards. Files are picked up automatically; any that are missing fall back to a built-in glyph.

| File | App |
|---|---|
| `netflix.png` | Netflix |
| `youtube.png` | YouTube |
| `prime.png` | Prime Video |
| `disney.png` | Disney+ |
| `spotify.png` | Spotify |

Use square PNGs (~256×256) with transparent backgrounds, downloaded from each company's official brand / press kit, and follow their logo-usage guidelines.
